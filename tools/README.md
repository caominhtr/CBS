## Tutorial to run PLEC fingerprint

The `PLEC_tutorial/` folder contains 5 example smina-generated poses, named `Ligand_1` to `Ligand_5`.

The tutorial script to generate PLEC fingerprints is saved in the PLEC_tutorial.py file and covers two scenarios:
(1) Generating a fingerprint for a single pose
(2) Generating fingerprints for a batch of ligands

To launch this tutorial, please run the following command in your terminal:

```
python PLEC_tutorial.py
```
